# Старт хакатона МосФорум

Здесь всё, чтобы за один заход превратить чистый компьютер в рабочее место,
одинаковое у всех участников: редактор, Claude Code, общие правила, скиллы,
плагины и код проектов.

**Опыт программирования не нужен.** Время: 40-60 минут, из них почти всё -
ожидание загрузок.

> **Работаешь с документами, а не с кодом?** (отчёты, Excel, Word, PDF)
> Тебе нужен офисный режим - он легче и ставит программы для документов
> вместо среды разработки. Порядок тот же: Cursor -> Claude -> команда
>
> ```bash
> curl -fsSL https://raw.githubusercontent.com/dimazaharov72-beep/mosforum-hackathon-start/main/bootstrap.sh | bash -s -- --office
> ```
>
> Уже настроенному компьютеру, где не нужно менять правила Claude, хватит
> только офисных программ: `bash office-tools.sh`.

---

## Что тебе понадобится

- Ноутбук на macOS или Windows 10/11, права администратора
- ~15 ГБ свободного места и стабильный интернет
- Аккаунт GitHub (если нет - заведи на [github.com](https://github.com), ник
  латиницей без пробелов, например `ivan-petrov-mf`)

---

## Шаг 1. Пришли Дмитрию свой ник GitHub

Без этого код проектов не скачается - репозитории закрытые.
Напиши ему ник в чат и продолжай, ждать не обязательно.

## Шаг 2. Поставь Cursor

Cursor - редактор, внутри которого будет работать Claude.

- **macOS:** скачай с [cursor.com/download](https://cursor.com/download),
  открой файл и перетащи Cursor в «Программы».
- **Windows:** скачай там же и запусти установщик.

Запусти Cursor. Если попросит войти, хватит бесплатного аккаунта.

## Шаг 3. Поставь Claude и войди

В Cursor открой терминал: меню `Terminal` → `New Terminal` (или `Ctrl+~`).

**macOS**

```bash
curl -fsSL https://claude.ai/install.sh | bash; grep -q '.local/bin' ~/.zshrc 2>/dev/null || echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.zshrc; exec zsh -l
```

**Windows** (PowerShell)

```powershell
irm https://claude.ai/install.ps1 | iex
```

Набери `claude` и Enter. Claude покажет **ссылку для входа** вида
`https://claude.ai/oauth/authorize?...`. **Скопируй её целиком и пришли
Дмитрию в чат.** Сам по ней не переходи - он активирует её со своей подпиской.

> Ссылка одноразовая и живёт ~10 минут. Никому, кроме Дмитрия, её не отправляй.

## Шаг 4. Дай Claude поставить всё остальное

Открой файл [`START.md`](START.md), скопируй промпт целиком и вставь в чат с
Claude. Дальше он ведёт установку сам: инструменты Apple, Homebrew, Node.js,
Docker, общие правила, скиллы, плагины, код проектов, Codex, и в конце
поднимает DayTrack.

От тебя понадобится только:

- **пароль от Mac** - его спросит системное окно «МосФорум: установка»,
  иногда несколько раз;
- **код GitHub** из 8 знаков - Claude покажет его, ты вводишь на
  github.com/login/device;
- **код Codex** - Claude покажет, ты пересылаешь Дмитрию.

> **Инструменты Apple.** Установка сначала ставит их тихо через «Обновление
> ПО», без окон. Если Apple откажет, откроется её окно «Установить». Если и
> оно не справится, установка остановится и скажет, где скачать инструменты
> вручную (нужен любой Apple ID), после чего продолжит с того же места.

<details>
<summary>Запасной путь: поставить без Claude, вручную в терминале</summary>

**macOS**

```bash
curl -fsSL https://raw.githubusercontent.com/dimazaharov72-beep/mosforum-hackathon-start/main/bootstrap.sh | bash
```

**Windows** (PowerShell от имени администратора)

```powershell
irm https://raw.githubusercontent.com/dimazaharov72-beep/mosforum-hackathon-start/main/bootstrap.ps1 | iex
```

Скрипт безопасный и повторяемый: если что-то не встало, запусти ещё раз.
Старые настройки Claude Code не стираются, а сохраняются рядом с пометкой
«бэкап». Потом вход в Codex (`codex login --device-auth`, код - Дмитрию) и
промпт из [`PROMPT.md`](PROMPT.md).

</details>

## Шаг 5. Скажи, что готов

Когда в браузере открылся экран входа DayTrack и ты смог залогиниться -
напиши Дмитрию «всё работает».

## Что в итоге стоит на машине

| Что | Зачем |
|---|---|
| Cursor | редактор кода |
| Claude Code | ИИ-помощник, работает внутри Cursor |
| Node.js 22 | на нём запускается проект |
| Docker Desktop | в нём крутится база данных |
| GitHub CLI (`gh`) | вход в GitHub и скачивание кода |
| `~/.claude/CLAUDE.md` | общие правила работы, одинаковые у всех |
| `~/.claude/skills` | 38 готовых навыков: дизайн, документы, тесты, анимация |
| Плагины superpowers, playwright и codex | процессы разработки, проверка в браузере, ревью второй нейросетью |
| `~/hackathon/` | папка с кодом проектов |

## Главные правила хакатона

- Работаешь в своей ветке: `feature/что-делаешь`.
- **В `main` напрямую не пушим.** Готово - открываешь pull request.
- **Выкат на прод делает только Дмитрий.** Твоя работа заканчивается на pull
  request, он смотрит и мерджит.
- Пароли, ключи и токены не выкладываем никуда - ни в код, ни в чат.

2. Не понял, что он хочет - напиши «объясни проще».
3. Совсем тупик - скриншот Дмитрию.

Не пытайся понять, как всё устроено, с первого раза. Задача этого дня -
чтобы просто заработало.
