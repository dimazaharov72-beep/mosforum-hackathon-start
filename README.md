# Старт хакатона МосФорум

Здесь всё, чтобы за один заход превратить чистый компьютер в рабочее место,
одинаковое у всех участников: редактор, Claude Code, общие правила, скиллы,
плагины и код проектов.

**Опыт программирования не нужен.** Время: 40-60 минут, из них почти всё -
ожидание загрузок.

---

## Что тебе понадобится

- Ноутбук на macOS или Windows 10/11, права администратора
- ~15 ГБ свободного места и стабильный интернет
- Аккаунт GitHub (если нет - заведи на [github.com](https://github.com), ник
  латиницей без пробелов, например `ivan-petrov-mf`)

---

## Шаг 1. Пришли Дмитрию свой ник GitHub

Без этого код проектов не скачается - репозитории закрытые.
Напиши ему ник в чат и продолжай, ждать не обязательно.

## Шаг 2. Запусти установку

Открой терминал.

- **macOS:** Spotlight (`Cmd+пробел`) → набери `Терминал` → Enter
- **Windows:** «Пуск» → набери `PowerShell` → правой кнопкой → **Запуск от
  имени администратора**

Скопируй команду целиком и вставь в терминал:

**macOS**

```bash
curl -fsSL https://raw.githubusercontent.com/dimazaharov72-beep/mosforum-hackathon-start/main/bootstrap.sh | bash
```

**Windows**

```powershell
irm https://raw.githubusercontent.com/dimazaharov72-beep/mosforum-hackathon-start/main/bootstrap.ps1 | iex
```

> Ничего ставить заранее не нужно: команда работает на чистой системе.

Скрипт ставит по шагам: инструменты разработчика, Homebrew (Mac) или winget
(Windows), git, GitHub CLI, Node.js 22, редактор Cursor, Docker Desktop,
Claude Code, общие правила и 38 скиллов, плагины, и скачивает репозитории
в папку `hackathon`.

Он **безопасный и повторяемый**: если что-то не встало - запусти ещё раз,
он доделает пропущенное. Старые настройки Claude Code не стираются, а
сохраняются рядом с пометкой «бэкап».

В конце скрипт напечатает либо «Всё готово», либо список замечаний.
Замечания просто скопируй в чат с Claude Code - он их починит.

## Шаг 3. Подключись к Claude

1. Открой **Cursor** → `File` → `Open Folder` → папка `hackathon/MosForum-DayTrack`
2. Открой в Cursor терминал (`Ctrl+~` или меню `Terminal` → `New Terminal`)
3. Набери `claude` и Enter
4. Claude покажет **ссылку для входа** вида `https://claude.ai/oauth/authorize?...`
   или код устройства
5. **Скопируй эту ссылку целиком и пришли Дмитрию в чат.** Сам по ней не
   переходи - он активирует её со своей подпиской
6. Дождись сообщения «активировал»

> Ссылка одноразовая и живёт ~10 минут. Никому, кроме Дмитрия, её не отправляй.

## Шаг 4. Дай Claude Code доделать остальное

Открой файл [`PROMPT.md`](PROMPT.md), скопируй оттуда промпт целиком и вставь
в чат с Claude Code. Он поднимет базу данных, соберёт проект и запустит его.

Дальше отвечай ему по-русски. Ошибку, которую не понимаешь, просто копируй
обратно в чат - он умеет себя чинить.

## Шаг 5. Скажи, что готов

Когда в браузере открылся экран входа DayTrack и ты смог залогиниться -
напиши Дмитрию «всё работает».

## Что в итоге стоит на машине

| Что | Зачем |
|---|---|
| Cursor | редактор кода |
| Claude Code | ИИ-помощник, работает внутри Cursor |
| Node.js 22 | на нём запускается проект |
| Docker Desktop | в нём крутится база данных |
| GitHub CLI (`gh`) | вход в GitHub и скачивание кода |
| `~/.claude/CLAUDE.md` | общие правила работы, одинаковые у всех |
| `~/.claude/skills` | 38 готовых навыков: дизайн, документы, тесты, анимация |
| Плагины superpowers и playwright | процессы разработки и проверка в браузере |
| `~/hackathon/` | папка с кодом проектов |

---

## Главные правила хакатона

- Работаешь в своей ветке: `feature/что-делаешь`.
- **В `main` напрямую не пушим.** Готово - открываешь pull request.
- **Выкат на прод делает только Дмитрий.** Твоя работа заканчивается на pull
  request, он смотрит и мерджит.
- Пароли, ключи и токены не выкладываем никуда - ни в код, ни в чат.

---

## Если застрял

1. Скопируй ошибку в чат с Claude Code, напиши «почини».
2. Не понял, что он хочет - напиши «объясни проще».
3. Совсем тупик - скриншот Дмитрию.

Не пытайся понять, как всё устроено, с первого раза. Задача этого дня -
чтобы просто заработало.
